PROJECT 01 MULTI-AGENT AI · FINANCIAL SYSTEMS
Code

QUANTUM AI RESEARCH AGENT

FastAPI React Python Pandas yFinance Multi-Agent AI

A service-oriented financial research system that decomposes investment analysis into specialized AI agents and combines their independent analysis into a final recommendation.

ENGINEERING CHALLENGE & SOLUTION

An initial single-LLM-prompt approach produced inconsistent and difficult-to-interpret results. The system was redesigned around four specialized agents: Technical, Fundamental, Sentiment, and Master Synthesis.

CORE ARCHITECTURE HIGHLIGHTS:
  • 4-agent service-oriented architecture (Technical, Fundamental, Sentiment, Master Synthesis)
  • Confidence-scored independent analysis with consensus-based synthesis
  • Deterministic Buy / Hold / Sell investment recommendation output
  • Integrates 3 live external financial data sources
  • Evaluates 5 financial timeframes from 15m to 1W
  • In-memory API response caching to eliminate redundant data fetches
  • Decoupled React + FastAPI full-stack platform
  • Real-time structured investment insights generation
